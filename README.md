# وب‌سایت ابنیه سازان پایدار شمیران

نسخه استاتیک دوزبانه و واکنش‌گرا، آماده انتشار در GitHub Pages.

## انتشار

تمام فایل‌های این پوشه را در ریشه مخزن `abnieh-sazan-paydar.github.io` قرار دهید. سپس در تنظیمات مخزن، از بخش **Pages**، گزینه **Deploy from a branch** و شاخه `main` / پوشه `/ (root)` را انتخاب کنید.

## نکته فرم

فرم نسخه فعلی، پیام پروژه را در واتساپ باز می‌کند. GitHub Pages بک‌اند و فضای امن بارگذاری فایل ندارد؛ برای ذخیره واقعی فایل‌ها باید در مرحله بعد یک سرویس ذخیره‌سازی متصل شود.
