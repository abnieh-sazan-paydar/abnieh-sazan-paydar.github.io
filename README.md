# بسته اصلاحی وب‌سایت ابنیه سازان پایدار شمیران

این بسته یک نسخه کامل و آماده جایگزینی برای مخزن GitHub Pages است.

## تغییرات اعمال‌شده
- بزرگ‌تر و خواناتر شدن نشان و نام شرکت در هدر
- اصلاح مقیاس و تناسب فونت‌ها در دسکتاپ و موبایل
- بازطراحی واکنش‌گرا و حرفه‌ای صفحات اصلی
- نمایش قطعی پروژه‌ها از طریق فایل `projects.json`
- دسته‌بندی پروژه‌ها بر اساس «نظارت فنی» و «اجرا»
- حذف عبارت «اجرایی» از پروژه‌های نظارتی و درج دقیق «نظارت فنی»
- اضافه‌شدن چهار مجموعه پروژه و ۸۰ تصویر ارسالی
- ساخت گالری سبک با تصاویر بندانگشتی و نسخه بزرگ
- بهینه‌سازی حجم تصاویر برای بارگذاری سریع‌تر در GitHub Pages

## روش اعمال
1. از مخزن فعلی یک نسخه پشتیبان بگیرید.
2. همه محتویات داخل این پوشه را در ریشه مخزن جایگزین کنید.
3. تغییرات را Commit کنید.
4. چند دقیقه برای انتشار GitHub Pages صبر کنید و صفحه را با Ctrl+F5 بازخوانی کنید.

## نکته
لینک واتساپ در `index.html` فعلاً روی `https://wa.me/` قرار دارد. شماره موردنظر را به صورت بین‌المللی بدون + جایگزین کنید.
